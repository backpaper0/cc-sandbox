# 04: code-server統合

**What to build:** 本体コンテナにcode-serverが同居し、`127.0.0.1`限定・パスワード認証で起動する。`up`の出力にアクセスURLとパスワードの確認方法が表示され、ブラウザでファイルツリー・Markdownプレビュー付きの編集ができる。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] code-serverが本体コンテナに同居して動く
- [ ] `127.0.0.1`にのみバインドされ、他マシン（LAN上の別端末）からは到達できない
- [ ] アクセスにパスワード認証が必須になっている
- [ ] `up`の出力にアクセスURLとパスワードの取得方法が表示される
- [ ] ブラウザからファイルツリーとMarkdownプレビューが使える
