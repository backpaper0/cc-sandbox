# ヘルプ・ユーザー向けドキュメントは英語ではなく日本語で統一する

`README.md`・`CONTEXT.md`・ADR・issue tracker（`.scratch/`）は既に日本語で書かれてきた一方、`bin/cc-sandbox`の`usage()`関数とエラーメッセージ、`bin/test-e2e`の`--help`出力とエラーメッセージ、`sandbox/isolate-forward.sh`のエラーメッセージ、`docs/e2e-testing.md`は英語のまま取り残されていた。本ツールの開発者・想定利用者はいずれも日本語話者であるため、これらも日本語に統一する。

対象はユーザーが実際に読む文言（usageの説明、エラーメッセージ、手順書）に限る。CLIのサブコマンド名・オプション名（`up`/`down`/`list`/`exec`/`password`、`--profile`等のリテラルな入力文字列）はコピペで動作しなくなるため英語のまま残す。コード内コメント、コミットメッセージ、`docs/agents/*.md`（`writing-for-agents`系スキルの規約に従うAIエージェント向け指示書）はユーザー向けの文言ではないため対象外とする。

既存の`.bats`テストはヘルプ/エラーメッセージの文字列をアサートしていないため、この変更によるテスト破壊はない。

## Considered Options

- 英語のまま統一する — 非日本語話者への配慮を優先する案。しかし本ツールの開発者・利用者はいずれも日本語話者であり、英語で書き続けるコストに見合うメリットがないため見送った。
- 日英併記にする — 英語話者にも開かれる利点はあるが、変更のたびに2言語分を更新する同期コストが発生するため見送った。
